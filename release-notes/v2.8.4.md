# Block N Load Community Fixes V2 — 2.8.4

## Performance and stability

- Fixed the severe first-match FPS regression caused by the auto-casual-queue runtime scanning every Unity object once per rendered frame.
- Added a safe animation guard for missing or invalid character animation states.
- Removed the experimental debug menu and its runtime logging code.
- Added optional continuous in-match performance telemetry and an allocation-conscious FPS counter.
- Added tested minimap and world-space-indicator update throttling controls.

## Launcher updates

- Fixed refresh logic that left the originally downloaded launcher on an older version after an update.
- Made external launcher replacement independent of Windows executable metadata so Linux single-file launchers update correctly.
- Added a regression test covering updates from multi-file installations and verification of both launcher copies.
- Bumped both Windows and Linux launcher builds to 2.8.4.

## Skins

- Added the Hindu Yeti skin and Darklord Sweet Science skin.
