## What's new

- Keeps the cross-platform `Avalonia` launcher introduced in `2.6.0`
- Keeps platform-aware update manifests with per-RID launcher assets

## Hotfixes

- Fixed bundled patching asset extraction in published launchers
- Fixed Windows Avalonia single-file publish by forcing native Skia libraries to self-extract at runtime
- Fixed launchers that appeared to do nothing on startup because the UI renderer could not load native dependencies

## Notes

- `launcher_exe` remains in the manifest as a Windows compatibility alias
- Manifest entries continue to expose `launcher_win_x64` and `launcher_linux_x64`
