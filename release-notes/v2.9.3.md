# BNL Community Fixes 2.9.3

BNL Reloaded storage cleanup update.

- Removes completed BNL Reloaded beta ZIPs after a successful installation.
- Cleans ZIPs left by older launcher versions the next time BNL Reloaded is launched.
- Removes stale partial downloads while preserving the current interrupted download for resume.
- Keeps only the active installed beta after an update, avoiding several gigabytes of accumulated archives.
