# v2.3.0

## New Features
- Auto casual queue: automatically joins the casual matchmaking queue when you enter a custom game lobby.
- When a casual match is found while you are in a custom game, the runtime exits via the in-match zone exit path and leaves the queue popup for manual acceptance. Enable via Feature Settings > Auto Queue tab. Can also be toggled live in-game with F8.

## Fixes
- Fixed a crash on launch when a feature config file is present but `Assembly-CSharp-backup.dll` has not yet been created (first-time feature users).
- Fixed same-version launcher bootstrapping so rebuilt 2.3 executables and bundled patching assets refresh correctly.
- Ensured freshly built experimental assemblies are deployed on launch.
