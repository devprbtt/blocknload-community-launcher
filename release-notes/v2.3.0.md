# v2.3.0

## New Features
- Auto casual queue: automatically joins the casual matchmaking queue when you enter a custom game lobby, and auto-accepts the match popup when a game is found. Enable via Feature Settings → Auto Queue tab. Can also be toggled live in-game with F8.

## Fixes
- Fixed a crash on launch when a feature config file is present but `Assembly-CSharp-backup.dll` has not yet been created (first-time feature users).
