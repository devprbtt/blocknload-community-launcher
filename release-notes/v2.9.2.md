# BNL Community Fixes 2.9.2

BNL Reloaded download and installation feedback hotfix.

- Shows a determinate progress bar, percentage, and transferred MiB while downloading.
- Shows extraction progress while installing and an indeterminate finalization state while removing the previous version.
- Runs archive extraction away from the UI thread so the launcher remains responsive.
- Clears installation progress after launch and reports the selected running server.
