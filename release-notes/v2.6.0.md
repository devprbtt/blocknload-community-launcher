## What's new

- Added a cross-platform `Avalonia` launcher project as the new release target
- Added platform-aware update manifests with per-RID launcher assets
- Added Linux-aware launcher asset selection in the updater flow
- Migrated more launcher/runtime services into `Core` for shared use between Windows and cross-platform frontends
- Added Linux-friendly command resolution and path handling improvements across launch, Steam, and file-opening flows

## Included fixes

- Local update smoke tests now target the Avalonia launcher
- Headless smoke test mode now exercises the update path instead of exiting too early
- Update helper install/restart now preserves executable bits on Unix-like systems
- Restart/update path handling is safer on Linux case-sensitive filesystems

## Notes

- `launcher_exe` remains in the manifest as a Windows compatibility alias
- New manifests now also expose keys like `launcher_win_x64` and `launcher_linux_x64`
