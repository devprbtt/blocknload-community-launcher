## v2.1.15

### Bug Fixes
- **Damage and healing numbers no longer float** — numbers are now attached to each player's healthbar UI via `AttachToHealthbarUi()`. When you turn the camera, numbers stay locked to the correct player instead of appearing at wrong screen positions.
- **Healing number size no longer grows each heal** — `ApplyHealTextAndColor` now has an `applySize` parameter that prevents the font size multiplier from being applied on every refresh call.
- **Fixed `MissingMethodException: FieldInfo.op_Equality`** — all `FieldInfo` comparisons now use `object.ReferenceEquals()` instead of `==` for Unity 5 Mono compatibility.
- **`GuiFollow` disabled immediately** — changed from `Destroy()` to `enabled = false` + `Destroy()` to prevent GuiFollow from repositioning numbers on the same frame after reparenting.

### Changes
- Default damage number size changed from **1.0 to 2.0**
- Default heal number size changed from **1.0 to 2.0**
- Healthbar-attached number Y offset increased from 30 to 65

### Technical Details
- Added `HashSet<int>` guard in `AttachToHealthbarUi()` to ensure attachment runs only once per number instance
- Uses reflection to access `GuiHealthbar.maker` field for matching healthbar UI to unit
- Numbers are reparented to `GuiHealthbar.Content.transform` and inherit correct canvas positioning
