## What's new

- Added complete Simplified Chinese localization across the launcher UI.
- Chinese localization covers the main window, feature settings and descriptions, setup, replay browser, replacers, custom servers, update screens, dialogs, errors and live status text.
- The launcher automatically uses Chinese when the operating-system UI language starts with `zh`.
- The language can also be forced with the `BNL_LANGUAGE=zh-CN` environment variable.

## Offline Bot Mode

- Includes automatic offline-server installation for Windows and Linux x64.
- Includes the canonical bnlReloaded map set.
- Retains the improved bot team composition, stair, slope and obstacle navigation.
- Stops the embedded server when the game or launcher closes.
