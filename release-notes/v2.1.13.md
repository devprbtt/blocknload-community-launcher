## v2.1.13

### New Features
- **Aim Healthbar**: Enemy healthbars now appear when you aim at them. Shows the enemy name and health bar while your crosshair is over them.

### Bug Fixes
- Fixed `NullReferenceException` spam in `ZoneServiceListener.Damage` and `ZoneServiceListener.UnitUpdate`
- Fixed `TypeLoadException: A type load exception has occurred at GuiHitAlertMaker.Start()` — caused by Unity 5.1.4's Mono failing to resolve `EventSource<GlobalUnitHealthChangeArgs>` across platform assembly boundaries. Fixed by removing `HealAlertBridge` and `HealingNumberBridge` MonoBehaviours from `BnlCommunityFixes.dll` and using reflection-based health change subscription instead.
- Fixed `TypeLoadException: A type load exception has occurred at GuiDamageNumberDetector.Start()` — same root cause and fix as above.
- Fixed `MissingMethodException: FieldInfo.op_Equality` that appeared after the initial TypeLoad fix — Unity 5's Mono (based on .NET 3.5) doesn't have this operator. Replaced with `object.ReferenceEquals()`.

### Technical Details
- Removed `HealAlertBridge` and `HealingNumberBridge` MonoBehaviour classes from the inline C# helper source in `Build-ExperimentalCrosshairAssembly.ps1`
- Replaced `AddComponent<T>()` approach with `System.Reflection`-based subscription to `ZoneMessenger.OnGlobalUnitHealthChange`
- All null checks on reflection types (`FieldInfo`, `MethodInfo`, `Delegate`) now use `object.ReferenceEquals()` for maximum Mono compatibility
