## What's new

- Bot / Offline Practice Mode now fills a complete 5v5 lobby with at most nine bots.
- Full teams target a 2 Brains, 2 Brawn and 1 Skill class composition.
- Bots can sprint-jump over one- and two-block obstacles and traverse stairs and directional slope blocks.
- Bot navigation now checks the hero footprint, avoids entering solid blocks and recalculates blocked paths.

## Fixes

- The embedded offline server stops when Block N Load exits or when the launcher closes.
- Fixed the embedded server package requiring a separately installed .NET 10 runtime.
- Bot Mode now downloads and installs the matching offline-server bundle automatically when it is missing.
- Fixed stair climbs being cancelled when the bot touched the vertical face before clearing the ledge.
- The Linux launcher now resolves the native Linux offline-server executable.

## Notes

- Includes self-contained Windows and Linux x64 launchers.
- Includes self-contained Windows and Linux x64 offline-server bundles.
