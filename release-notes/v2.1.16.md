## v2.1.17

### Changes
- Predicted saucer projectile drop: Astro saucers now detonate locally on timeout or right-click, with server reconciliation
- FOV feature re-enabled and migrated to offset-based IL patching for CameraFov and CameraArms
- Weapon model FOV now reads from fov-config properly
- Cached component references in AdsSensitivityRuntime to avoid FindObjectOfType performance hit
- Removed Insert-CallAtStart injection for FOV (caused InvalidProgramException)
- Fixed orphaned closing brace that broke the experimental assembly build

## v2.1.16

### Fixes
- Removed the runtime menu dependency on external framework assemblies that were crashing the injected helper at runtime
- Replaced runtime menu persistence with a plain-text config format
- Disabled the FOV feature path in the experimental assembly builder for now to stop the `CameraFov.Update()` runtime regression

### Runtime Menu
- `F8` toggles the menu
- `Up` / `Down` selects a setting
- `Left` / `Right` changes the selected value
- `F5` saves
- `F6` resets defaults

### Notes
- FOV settings are temporarily ignored by this build while that feature path is quarantined
