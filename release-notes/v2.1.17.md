## v2.1.17

### New Features
- **Predicted saucer projectile drop** — Astro saucers now detonate locally on timeout or right-click, with server reconciliation. Added `PredictedProjectileRuntime` helper class with HashSet-based double-detonation guard.
- **Path Hud.Update()** for per-frame right-click detonation detection.
- **ProjectileRegistry iteration via reflection** for finding local player's server-owned grenades.

### Bug Fixes
- FOV feature re-enabled (`$EnableFovFeature = $true`) and migrated to offset-based IL patching for CameraFov and CameraArms (same approach as the old working `fov150` bundle)
- Weapon model FOV now reads from `fov-config.json` properly instead of hardcoded 30
- Fixed `InvalidProgramException` in CameraFov/CameraArms caused by Insert-CallAtStart injecting bare `call` without arguments
- Fixed `FindObjectOfType` performance issue — cached component references in `AdsSensitivityRuntime`
- Fixed orphaned closing brace that broke the experimental assembly build
- Fixed unused `activeSaucerShotId` field causing C# compiler error
