# BNL Community Fixes 2.9.1

Closed-beta hotfix for the BNL Reloaded runtime package.

- Installs the upgraded Windows client and its AssetBundles as one atomic version.
- Rejects incomplete beta archives before replacing a working installation.
- Supplies BNL Reloaded with the detected vanilla game's Wwise sound-bank path.
- Preserves the exact host and port selected in the community launcher.
