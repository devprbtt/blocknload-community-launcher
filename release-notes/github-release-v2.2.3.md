# BNL Community Launcher v2.2.3

Small follow-up release for update diagnostics and first-launch performance after update.

## Changes
- Shows the launcher version in the window title, top-right UI, and status/details panel.
- Limits external launcher refresh to the newest bootstrap sources instead of every historical path in the launcher log.

## Fixes
- Reduces the long first startup delay after updating from older launchers.

## Files
- BnlCommunityFixes.exe
- BnlUpdater.exe
