## Performance fix

- Removed Audio Replacer, Mesh Replacer, and Texture Replacer, along with the shop icon override feature. These shared always-on texture-scanning code that ran continuously in the background even with the features disabled, and were the suspected cause of the FPS drops several players reported.
- Removed the Classic Scoreboard and Nigel Geometry Skin prototypes.

## New: Skins tab

- Added a dedicated "Skins" tab in Feature Settings, separate from Misc.
- Nigel Imported Rifle (Prototype) now lives there.

## New prototypes (opt-in, Skins/Misc tabs)

- Motion Blur (Prototype) — directional camera motion blur with adjustable strength, quality, and center focus.
- Color Grading / Sharpening (Prototype) — full-resolution sharpening and lightweight color grading for the world camera.
