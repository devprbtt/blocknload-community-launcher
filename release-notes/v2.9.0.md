# Block N Load Community Fixes V2 — 2.9.0

## BNL Reloaded closed beta

- Added secure Steam sign-in for invited closed-beta accounts.
- Added an opt-in BNL Reloaded mode that remains disabled by default.
- Added resumable, SHA-256-verified beta downloads and automatic update checks before launch.
- Launches the upgraded client without community mods and connects it to the exact host and port selected in the launcher server list.
- The closed beta currently supports Windows x64.

## Existing game

- The normal Block N Load launch and community-mod workflow are unchanged when BNL Reloaded is disabled.
