# BNL Community Fixes v2.4.5

Replay fidelity fixes for devices, projectiles, supplies, and explosives.

## Changes
- Improved replay placement fidelity for wall-attached devices and build-finished device orientation.
- Fixed several replay projectile paths and muzzle/orientation cases for Ninja, Sarge, and Djinn actions.
- Added replay capture and playback support for local projectile events needed for accurate trajectories.
- Fixed replay device health, destruction timing, placement sounds, and duplicate destruction visuals.
- Fixed supply/blockbuster visibility, landing behavior, health, and pickup visibility.
- Fixed supply crate parachutes staying attached after landing.
- Fixed dynamite timer playback using the original in-game countdown UI.
- Reduced false movement animation during replay idle/jitter states.
