## What's new

- Re-enabled the Time Assault menu entry in the Avalonia launcher and game patch flow so the mode can be launched again when enabled.
- Added Time Assault launcher settings support to config transfer and recommended-settings resource loading.

## Fixes

- Fixed Time Assault scene restart handling by bypassing the broken fast-restart path that could hang the reload at 100%.
- Time Assault helper runtime is now embedded and generated correctly during patch builds.

## Notes

- Release artifacts include both `win-x64` and `linux-x64` launchers.
